# Data sources

External data and services the app uses or links to.

* [Nominatim place search](nominatim.md) - Geocoding of free-text regions in Explore.
* [Open-Meteo Marine API (four models)](open-meteo-marine.md) - How wave, swell, tide and sea temperature data are requested and parsed.
* [Open-Meteo weather APIs](open-meteo-weather.md) - Wind, gusts, air temperature, sunrise and sunset for each session date.
* [OpenFreeMap and OpenStreetMap](openfreemap-osm.md) - Map tiles and the base for some spot positions.
* [Spot guide sources](spot-guide-sources.md) - Public guides the built-in spot guides were compiled from.
* [surf-forecast.com](surf-forecast.md) - Forecast conventions we match, and break slugs we link to.
* [Surfline](surfline.md) - The best-known surf service; source of spot names and the ids we link to.
* [Wikimedia Commons photos](wikimedia-commons.md) - Freely licensed spot photos with credits.
